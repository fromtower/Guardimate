# 🛡️ Guardimate

**해외 체류자·여행자를 위한 안전 동행 웹앱** — 위험 구역을 피해 가는 *안전 경로*를 계산하고, AI 안전 비서·원터치 SOS·보호자 실시간 동행 기능을 하나의 모바일 화면에 담았습니다.

> Safe Map · AI Core Chat · Emergency SOS · Settings, 4개 탭으로 구성된 단일 페이지 앱(SPA)이며 빌드 과정 없이 `index.html` 하나만 열면 실행됩니다.

---

## ✨ 주요 기능

### 🗺️ Safe Map — 위험 회피 안전 경로
- **실제 GPS 기반 경로 탐색**: 위치 권한을 허용하면 현재 위치에서 목적지까지 경로를 계산합니다. (권한 거부 시 뉴욕 데모 좌표로 동작)
- **안전 경로 vs 최단 경로 비교**: Safe Path 토글로 두 경로를 전환하며, 각 경로의 **안전 점수(0~100)** 와 ETA를 함께 보여줍니다.
- **위험 구역 4종**: 치안 위험 · 재난/침수 · 인프라 차단 · 커뮤니티 제보. 카테고리별로 켜고 끌 수 있습니다.
- **🌙 심야 위험 가중**: 야간(21~06시)에는 치안 구역 반경을 자동 확대해 우회를 강화합니다.
- **목적지 검색**: Photon / Nominatim 지오코딩으로 장소를 검색하거나, 지도를 탭해 목적지를 바로 지정할 수 있습니다.
- **도보 / 자동차** 이동 수단 전환.
- **주변 안전 시설 표시**: 경로 주변 2km 이내 경찰서 👮 · 소방서 🚒 · 병원 🏥 (Overpass API).
- **실시간 날씨 경보** (OpenWeatherMap) 및 **주변 위험·통제 뉴스** (GNews).
- **🚩 커뮤니티 위험 제보**: 지도를 길게 누르거나 제보 버튼으로 가로등 고장·공사·침수·치안 불안을 등록합니다. 제보는 1/6/24시간 유지되며 즉시 안전 경로 계산에 반영됩니다.

### 🛡 보호자 실시간 동행 (Guardian Escort)
- 동행을 시작하면 1분마다 보호자에게 현재 위치를 공유합니다.
- **경로 이탈**(안전 경로에서 50m 이상, 60초 지속), **장시간 정지**(3분 이상), **목적지 도착**(40m 이내)을 자동 감지해 알립니다.

### 🤖 AI Core Chat
- **Google Gemini(gemini-2.5-flash)** 연동 AI 안전 비서. 현재 경로·위험 구역·날씨 등 앱 상태를 컨텍스트로 전달해 상황에 맞는 답변을 제공합니다.
- API 연결 실패 시 **내장 오프라인 어시스턴트**가 자동으로 대신 답변합니다.
- 빠른 질문 버튼: 가장 안전한 경로 / 주변 위험 요약 / 심야 귀가 수칙 / 응급 대처 요령.

### 🚨 Emergency SOS
- **원터치 SOS**: 버튼을 누르면 5초 카운트다운 후 보호자에게 현재 위치(Google Maps 링크)와 긴급 알림을 전송합니다. 카운트다운 중 취소 가능.
- **⏱ 안전 타이머(도착 체크인)**: 15/30/60분 중 선택. 시간 내 '무사 도착'을 누르지 않으면 마지막 위치와 함께 미응답 알림이 자동 전송됩니다.
- **현지 긴급 연락처**: 현지 긴급번호, 대한민국 영사콜센터(+82-2-3210-0404), 지정 보호자.
- 알림은 **Telegram Bot API**를 통해 전송됩니다.

### ⚙️ Settings
- **7개 언어**: 한국어 · English · 日本語 · 中文 · Español · Deutsch · Français
- **7가지 테마**: Light · Dark · 봄 🌸 · 여름 ☀️ · 가을 🍁 · 겨울 🎄 · 할로윈 🎃 — 색상·밝기·로고·장식 효과(눈, 낙엽, 벚꽃 등)가 함께 바뀝니다.
- 지도 스타일(다크 / 표준 / 위성), 위험 알림 카테고리, 보호자 번호, 영사콜센터 연동, Gemini API 키 설정.
- 🧪 **타이머 테스트 모드**: 안전 타이머를 15초로 단축하고 동행 임계값을 줄여 알림 동작을 빠르게 확인할 수 있습니다.
